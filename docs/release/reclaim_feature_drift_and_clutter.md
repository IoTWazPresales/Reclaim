## Add complexity without strengthening core promise

| Area | Note | Recommendation |
|------|------|----------------|
| **Dashboard routines + schedule overlay** | Supports **structure**; increases cognitive load | **Keep** if tied to recovery stages; **merge** UI where redundant with “today” |
| **Multiple notification schedulers** | Daily signal, weekly narrative, mood trend, training, calendar, health | **Inference:** risk of **noise** vs “meaningful notifications” principle | **Audit** opt-outs + caps; **defer** new channels |
| **Analytics tab** | Mood/meditation stats — useful, not “one insight” | **Keep**; treat as **secondary** analytics, not home competitor |
| **Premium starfield + lifecycle hero + many tiles** | Premium **or** busy | **User test**; offer reduced chrome **Inference** |
